# Proyecto Final - Análisis de población y empleo en Costa Rica

## Descripción del proyecto

Este proyecto analiza datos de población y empleo en Costa Rica utilizando información del Banco Central de Costa Rica (BCCR)

El programa permite consultar diferentes indicadores, mostrar estadísticas, comparar períodos y visualizar la tasa de desempleo

---

## Archivos del proyecto

- `proyecto_final.py`: contiene el programa principal.
- `Población total por condición de actividad y tasas..csv`: contiene los datos utilizados para el análisis.

---

## Funciones principales

1. Mostrar datos principales.
2. Consultar indicadores.
3. Mostrar estadísticas de desempleo.
4. Graficar la tasa de desempleo.
5. Comparar dos períodos.

---

## Librerías utilizadas

- Pandas
- Matplotlib

---

## Ejecución

1. Tener Python instalado.
2. Tener disponibles las librerías Pandas y Matplotlib.
3. Verificar que el archivo CSV esté disponible.
4. Ejecutar `proyecto_final.py`.
5. Seleccionar una opción del menú.
